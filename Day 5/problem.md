## Day 5 – Understanding `foreach` Loop (Basics)

### Objective
To understand how the `foreach` loop iterates over a collection and executes the same logic for each item.

### Problem Statement
1. Create a list of environment names:
   - dev
   - test
   - prod
2. Use a `foreach` loop to iterate through the list.
3. Print each environment name with a descriptive message.

### Expected Outcome
The script should print each environment on a separate line with a clear label.
