## Day 7 – Basic File Reading and Counting

### Objective
Learn how to check if a file exists, read its content, and count the number of lines.

### Scenario
A file named `names.txt` contains a list of names:

Amit  
Sara  
John  
Priya  

### Task
1. Check if `names.txt` exists.
2. If it exists:
   - Read all names from the file.
   - Print each name in this format:

     Name: <name>

   - Print the total number of names.
3. If the file does not exist:
   - Print: File not found
